# Visuels à réaliser — file de Codex

Tâches artistiques confiées à Codex : visuels, animations, effets visuels, icônes, habillage et décor. Claude Code ajoute ici les besoins visuels qu'il rencontre en codant et ne les réalise pas lui-même. Codex coche ou retire une tâche quand il l'a livrée, et note la version concernée.

Format : une case par tâche, avec le contexte (mission, unité, écran), ce qui existe déjà et les contraintes (fichiers, taille, intégration attendue).

Décision du porteur du 10 novembre 2026 : le principe est validé, mais il hésite entre un emplacement recouvert de cendres et de la lave, à condition que l'effet reste cohérent avec l'unité présente (on doit voir que l'unité est désactivée). À livrer : visuel d'avertissement, visuel de désactivation, fin de désactivation ; lisibilité sur les six emplacements et avec toutes les unités ; fonctionnement à vitesse du jeu augmentée. Référence : `design/Missions_071_080_Eruptions.md`. Le son n'est pas abordé.
